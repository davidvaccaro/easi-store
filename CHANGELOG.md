# Changelog

## 0.1.0 — foundation preview

- Independent local archive built on EASI JS, SQLite, and filesystem object storage.
- Streaming ingestion preserves original instance bytes and records committed metadata, hashes, import outcomes, and duplicate/conflict decisions.
- Authenticated study library, synthetic demo, series/instance browsing, and embedded EASI View.
- Initial explicitly scoped QIDO, STOW, and original-DICOM WADO profile.
- Local DIMSE Verification and durable Storage SCP on AE `EASISTORE`, port 4248.
- Docker Compose local deployment, cross-platform source launchers, and portable artifact packaging with optional verified Node 24 runtime.
- Phased interoperability, research workflows, native installation, and production qualification backlog.

This first preview does not declare full DICOMweb conformance or Orthanc parity. See the capability matrix for exact implemented limits.
